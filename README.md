# Reverbs

This project is a [Heavy](https://github.com/Wasted-Audio/hvcc) port of the Pure Data reverb patches by [Tom Erbe](https://tre.ucsd.edu/wordpress/?p=625).

It is available under the BSD-3 license as is the original.

## Algorithms

- Allpass Chain
- [Schroeder](https://ccrma.stanford.edu/~jos/pasp/Schroeder_Reverberators.html) Reverberator
- [Moorer](https://kaud.io/projects/2401-moorer-reverb) Reverb
- [Moore](https://valhalladsp.wordpress.com/tag/time-varying/) Spacestation
- [Gerzon](https://ccrma.stanford.edu/~jos/pasp/History_FDNs_Artificial_Reverberation.html) Feedback Delay Network
- [Dattorro](https://ccrma.stanford.edu/~dattorro/EffectDesignPart1.pdf) Plate
